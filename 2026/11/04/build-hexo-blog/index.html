用 Hexo 从零搭一个博客（完整记录）

这个博客是用 Hexo 搭的，托管在 GitHub Pages 上，除了域名之外不花钱。把过程记下来，一是方便自己以后重装，二是给同样想搭博客的人省一点时间。

一、准备环境

需要两样东西：

  • Node.js（LTS 版本即可），安装后自带 npm；
  • Git，用来把生成的网页推送到 GitHub。

装完后在终端里确认：

二、初始化 Hexo

浏览器打开 http://localhost:4000，能看到默认页面就说明成功了。

三、写第一篇文章

命令会在 source/_posts/ 下生成一个 Markdown 文件。用任意编辑器打开，改标题、写正文，保存后刷新本地页面就能看到。

四、部署到 GitHub Pages

  1. 在 GitHub 新建仓库，仓库名必须是 <用户名>.github.io；
  2. 修改站点根目录的 _config.yml：
  1. 安装部署插件并推送：
  1. 到仓库的 Settings → Pages，确认分支是 main、目录是根目录，等一两分钟即可访问。

五、踩过的坑

  • 仓库名写错，页面会 404；
  • branch 和仓库默认分支不一致，部署会失败；
  • 国内访问 github.io 有时比较慢，可以换网络或挂代理再试；
  • 换电脑后要先 npm install，否则 hexo 命令跑不起来。

六、换成自己的主题

默认主题比较朴素。可以在 Hexo 主题站挑一个，把主题文件夹放进 themes/，再修改 _config.yml 里的 theme 字段。这个博客就是在默认主题上改的颜色和排版，改 themes/landscape/source/css/ 下的样式文件即可。

搭建本身只要一个下午，难的是之后持续写。与各位共勉。
